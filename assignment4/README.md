# Assignment 4: HTML, CSS, JavaScript

Four self-contained pages that share one color scheme, font and layout. Each file has its own inline CSS and JavaScript, so any one of them can be submitted to Gradescope on its own.

| File | Task |
| --- | --- |
| `validation.html` | Form with name, email and age. The Validate button checks that the name is not empty, the email has exactly one `@` with a `.` after it, and the age is a number above 18. Errors go into a `<p>` via `innerText`; a valid form shows an alert. |
| `sort.html` | Prompts for comma-separated numbers, converts them to an array, sorts them with Bubble Sort and shows the result in a textarea. |
| `counter.html` | Counts how often each word appears in a textarea, ignoring capitalization, and lists the lowercase words with their counts in a paragraph. |
| `guess.html` | The computer picks one random integer from 1 to 100. Each prompt guess gets a "Too High", "Too Low" or "Correct!" alert, and the page shows how many attempts it took. |

Open any file directly in a browser; no server is needed.
